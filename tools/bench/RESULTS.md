(5.4x3.2, fridge at run end) and an L+island (3.6x3.0). Each was sent
through the app's EXACT prompt + image pipeline (`bench_models.py`) to

dimensions (30), wall placement Jaccard (25), appliance positions (30),
island (15). "Distinct" = did the three drawings produce three different
